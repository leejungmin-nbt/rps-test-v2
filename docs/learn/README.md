# Firebase 쉽게 읽기

이 폴더는 Firebase 지식이 부족해도 기존 문서를 읽을 수 있도록 돕는 **보조 학습 문서**다.
정책 정본은 `docs/guide/`, 사용자 흐름은 `docs/flow/`, 구현 단위는 `docs/task/`를 따른다. 이 폴더는 정본을 바꾸지 않고 어려운 단어와 서비스 관계를 쉽게 풀어 설명한다.

## 먼저 읽는 순서

1. [Firebase 전체 그림](./01_Firebase_전체_그림.md)
   - Firebase가 이 프로젝트에서 어떤 역할을 하는지 큰 그림으로 본다.
2. [프로젝트 용어집](./02_프로젝트_용어집.md)
   - 문서에 자주 나오는 Firebase/서버리스 용어를 빠르게 찾는다.
3. [사용자 흐름으로 보는 Firebase](./03_흐름별_Firebase_읽기.md)
   - F01~F06 사용자 흐름에서 어떤 Firebase 서비스가 움직이는지 연결해서 본다.
4. [자주 헷갈리는 개념](./04_헷갈리는_개념_비교.md)
   - 비슷해 보이지만 역할이 다른 단어를 비교한다.

## 이 폴더의 역할

- 어려운 단어를 쉬운 말로 설명한다.
- “왜 이 서비스가 필요한지”를 프로젝트 흐름에 맞춰 설명한다.
- guide/task 문서로 넘어가기 전 예습 자료 역할을 한다.

## 이 폴더가 하지 않는 것

- Firebase 공식 문서나 최신 제한값을 대체하지 않는다.
- 요금, quota, IAM 세부 설정값을 확정하지 않는다.
- 구현 정책을 새로 결정하지 않는다.

정확한 운영 설정과 정책은 다음 문서를 따른다.

- [6. 데이터 모델 및 보안 정책](../guide/06_데이터_모델_및_보안_정책.md)
- [8. 자동진행 및 서버리스 함수](../guide/08_자동진행_및_서버리스_함수.md)
- [9. 호스팅·배포·환경](../guide/09_호스팅_배포_환경.md)
