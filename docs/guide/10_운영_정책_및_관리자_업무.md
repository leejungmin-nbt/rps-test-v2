# 10. 운영 정책 및 관리자 업무

> 운영 전 상세화할 관리자 절차 문서다. 현재는 다른 장에서 위임한 운영 항목을 잃지 않기 위한 **경량 스텁**으로 둔다.

---

## 10.1 현재 상태

- 상세 운영 매뉴얼은 아직 작성하지 않는다.
- MVP/검증 단계에서는 Firebase 콘솔과 기존 검증 도구 중심으로 운영한다.
- 운영 리허설 또는 실제 배포 전 이 문서를 확장한다.

---

## 10.2 운영 전 작성할 항목

| 항목 | 작성 내용 |
|---|---|
| 행사 시작/종료 절차 | `appState/activeGameId` 설정, 이전 `games/{gameId}` 회차 정리, 시작 전 체크 |
| `minInstances` 운영 | 행사 전 활성화, 종료 후 비활성화, 담당자 |
| 우승자 확인/수동 지급 | `winnerId`, `clickKey`, 비공개 지급 정보 확인 절차 |
| 장애 대응 | batch 실패, manifest 실패, 라운드 멈춤 시 복구 절차 |
| 알림/보고 | 장애 알림 채널, 사고 보고 라인 |
| 감사/보존 | 지급 처리 기록, 개인정보 보존/삭제 정책 반영 |

---

## 10.3 작성 트리거

다음 중 하나가 확정되면 상세 문서로 확장한다.

- 운영 일정과 담당자가 정해진다.
- 우승자 지급 프로세스를 실제 운영자가 수행해야 한다.
- Cloud Tasks / Pub/Sub 기반 운영 모드로 전환한다.
- 부하 테스트 또는 운영 리허설을 진행한다.
