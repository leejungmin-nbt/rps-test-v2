# 11. 비용 추정

> 비용 수치를 운영 의사결정에 쓰기 위한 문서다. 현재는 기존 검토 문서의 범위를 연결하는 **경량 스텁**으로 둔다.

---

## 11.1 현재 기준

초기 기술 검토 기준의 대략적인 비용 가정은 다음과 같다.

| 시나리오 | 대략 비용 |
|---|---|
| 1회 행사, 1만 명 기준 | 약 `$1` ~ `$2` |
| 월 4회 정기 운영 | 약 `$5` ~ `$10` / 월 |
| 트래픽 폭증 5만~10만 | 약 `$25` ~ `$100` / 월 |

정확한 비용은 아직 부하 테스트와 실제 Firebase 사용량 측정 전이므로 확정값으로 보지 않는다.

---

## 11.2 운영 전 산정할 항목

| 항목 | 산정 내용 |
|---|---|
| Firestore reads/writes | 입장, 선택 제출, 라운드 집계, 결과 조회 |
| Cloud Functions | Callable, Cloud Tasks HTTP, Pub/Sub batch 처리 |
| Cloud Tasks / Pub/Sub | 라운드 전환 task, batch fan-out |
| Firebase Hosting | 인앱웹뷰 진입 트래픽, 정적 자산 전송량 |
| `minInstances` | 행사 전후 활성화 시간과 인스턴스 수별 비용 |
| dev/prd 분리 | 프로젝트 2개 운영 시 추가 비용 |

---

## 11.3 작성 트리거

- PM 비용 승인 자료가 필요하다.
- `minInstances` 값을 확정해야 한다.
- 1k / 5k / 1만 부하 테스트 결과가 나온다.
- dev/prd 분리 여부가 확정된다.
